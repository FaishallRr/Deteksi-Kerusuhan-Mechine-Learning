Latar Belakang:  
Sebagai asesmen akhir Mata Kuliah Pembelajaran Mesin, Ujian Akhir Semester ini mengambil 
bentuk Capstone Project yang mengintegrasikan seluruh konsep dan teknik yang telah dipelajari 
selama satu semester. Mahasiswa dituntut untuk mendemonstrasikan kemampuan end-to-end 
dalam menerapkan pipeline Machine Learning untuk menyelesaikan masalah dalam dunia nyata, 
mulai dari akuisisi data, eksplorasi dan preprocessing, pemodelan, evaluasi, hingga deployment 
model. Project ini dirancang untuk merefleksikan skenario pekerjaan sesungguhnya di Machine 
Learning, di mana kemampuan teknis harus dibarengi dengan kemahiran dalam komunikasi hasil 
dan penyajian solusi yang dapat diakses oleh stakeholder non-teknis. 
Tujuan Akhir UAS: 
Mengembangkan aplikasi berbasis model machine learning menggunakan Streamlit atau 
framework semisalnya yang mempresentasikan solusi Machine Learning komprehensif untuk 
suatu permasalahan dalam kehidupan nyata, dilengkapi dengan model terbaik yang telah dilatih, 
dokumentasi proses, dan evaluasi dan analisa mendalam, serta Teknik presentasi yang baik. 
 
SOAL 1: PROBLEM DEFINITION & DATA ACQUISITION 
[Bobot: 10% dari Nilai UAS] 
1. Pilih satu problem statement yang relevan dengan domain machine learning (contoh: 
prediksi churn pelanggan, klasifikasi sentimen review, prediksi harga rumah, deteksi fraud, 
rekomendasi produk, deteksi penyakit diabetes dll.). 
2. Identifikasi dan kumpulkan dataset yang sesuai. Sumber data dapat dari: 
o Platform publik (Kaggle, UCI Machine Learning Repository, data.gov, dll.) 
o API (Twitter, YouTube, Instagram, dll. dengan memperhatikan kebijakan 
penggunaan) 
o Data hasil scraping (dengan etika dan izin yang jelas) 
o Dataset pribadi (jika tersedia) 
3. Tuliskan latar belakang masalah, tujuan bisnis/analisis, dan metrik kesuksesan proyek. 
Keluaran Wajib: 
• 
Penjelasan tertulis tentang problem statement (min. 200 kata) 
• 
Link atau dokumentasi sumber dataset 
• 
Statistik deskriptif awal (ukuran data, jumlah fitur, tipe data, dll.) 
 
SOAL 2: EXPLORATORY DATA ANALYSIS & PREPROCESSING 
[Bobot: 20% dari Nilai UAS] 
Lakukan eksplorasi dan preparasi data menyeluruh dengan: 
1. Analisis kualitas data (missing values, outliers, duplikat, inconsistency) 
2. Analisis univariat dan multivariat (distribusi, korelasi, pola menarik) 
3. Visualisasi insights kunci menggunakan Matplotlib/Seaborn/Plotly 
4. Feature engineering dan preprocessing (handling missing values, encoding, scaling, feature 
selection, dll.) 
5. Pembagian dataset (train-validation-test split) 
Keluaran Wajib: 
• 
Notebook EDA lengkap dengan visualisasi dan penjelasan 
• 
Dokumentasi setiap langkah preprocessing dan justifikasi teknik yang dipilih 
• 
Visualisasi 5 insights paling penting dari data

SOAL 3: MODELING & EVALUATION 
[Bobot: 30% dari Nilai UAS] 
Bangun dan evaluasi model Machine Learning dengan: 
1. Implementasi minimal 2 model berbeda (contoh: Logistic Regression, Random Forest, XGBoost, 
SVM, Neural Network) 
2. Tuning hyperparameter menggunakan teknik yang tepat ( contoh : Optuna, Grid Search, Random 
Search, Bayesian Optimization) 
3. Evaluasi komprehensif menggunakan metrik yang relevan: 
o 
Untuk klasifikasi: Accuracy, Precision, Recall, F1-Score, ROC-AUC, Confusion Matrix 
o 
Untuk regresi: R², MSE, RMSE, MAE, Residual Analysis 
4. Analisis feature importance/model interpretasi (SHAP, LIME, permutation importance, dll.) 
5. Pemilihan model terbaik beserta justifikasi 
Keluaran Wajib: 
• 
Kode training dan tuning model 
• 
Tabel perbandingan performa semua model 
• 
Visualisasi hasil evaluasi (ROC curves, confusion matrix, residual plots, dll.) 
• 
Penjelasan model terbaik dan interpretasi hasil 
 
SOAL 4: DEPLOYMENT & STREAMLIT APPLICATION 
[Bobot: 25% dari Nilai UAS] 
Buat aplikasi web interaktif menggunakan Streamlit atau framework yang semisal dengan memuat: 
1. Dashboard EDA - visualisasi interaktif dari analisis data 
2. Model Demo - interface untuk input data dan mendapatkan prediksi dari model terbaik 
3. Evaluasi Model - tampilan metrik dan visualisasi evaluasi model 
4. Interpretasi Hasil - penjelasan model dan insights bisnis 
5. Dokumentasi - penjelasan tentang dataset, metodologi, dan cara penggunaan aplikasi 
Keluaran Wajib: 
• 
Aplikasi Streamlit yang di-deploy (Streamlit Community Cloud/GitHub/Heroku) 
• 
Kode aplikasi lengkap (app.py, model pickle, requirements.txt) 
• 
Screenshot antarmuka aplikasi 
 
SOAL 5: DOCUMENTATION & PRESENTATION 
[Bobot: 15% dari Nilai UAS] 
Buat dokumentasi proyek yang komprehensif: 
1. Laporan Teknis (format PDF) yang mencakup: 
o 
Pendahuluan dan latar belakang 
o 
Metodologi (alur kerja, teknik yang digunakan) 
o 
Hasil dan analisis 
o 
Kesimpulan dan rekomendasi 
o 
Referensi 
2. Presentasi Youtube yang merangkum proyek untuk audiens. 
3. Repository GitHub yang terstruktur dengan: 
o 
README.md yang informatif 
o 
Struktur folder yang rapi 
o 
Kode yang terdokumentasi dengan baik 
 
CATATAN KETENTUAN TEKNIS : 
1. Bahasa Pemrograman: Python 
2. Libraries Wajib: 
o 
Data Manipulation: Pandas, NumPy 
o 
Visualization: Matplotlib, Seaborn, Plotly 
o 
Machine Learning: Scikit-learn, XGBoost/LightGBM/CatBoost (pilih salah satu) 
o 
Model Interpretation: SHAP atau LIME 
o 
Deployment: Streamlit, Pickle/Joblib, dan semisalnya.
